# 帮助 {#help}

谁都会有需要帮一把的时候。别让几个小障碍挡住你做出点了不起的东西。

## 社区支持 {#community-support}

如果你是开发者，想贡献代码、文档或参与讨论，
我们非常乐意通过 [GitHub issues][gh-issues] 做出说明、回答问题。
你也可以加入我们的 [Slack 群组](https://ohif.org/community)，
或者到[社区论坛](https://community.ohif.org/)发帖。

提报缺陷和功能请求（包括文档不完整或含混不清的问题），
[GitHub issues][gh-issues] 依然是最好的沟通渠道。

与你所在组织 / 具体情形强相关的复杂问题也可以发，
但得到回复的可能性会低一些。很遗憾，我们的资源有限，
必须谨慎分配。如果你正处在这种情况、又确实需要协助，
那么寻求付费支持可能对你更有利。

[gh-issues]: https://github.com/cornerstonejs/cornerstone3D/issues/

:::note 关于本中文文档

上面这些渠道都是**官方英文**社区的。如果你的问题是关于**这份中文翻译**的
（译文有误、术语不一致、内容过时等），请到
[翻译仓库](https://github.com/CuiBenyong/cornerstone3d-zh) 提 Issue。

:::
